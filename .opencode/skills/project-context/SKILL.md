# Contexto del proyecto

Antes de trabajar:
1. Lee `AGENTS.md`.
2. Inspecciona `docs/` y las notas de producto relevantes disponibles en el workspace.
3. Identifica decisiones aprobadas, propuestas y pendientes.
4. Si Obsidian está fuera del workspace, dilo; no afirmes haber leído el vault.
5. No inventes el contenido faltante del Documento 08.
6. Mantén Next.js BFF → Express, aislamiento multi-tenant en backend, RBAC y suscripciones separadas.
7. Resume qué decisiones condicionan la tarea antes de editar.
