# Sincronización documental

- Identifica qué archivos de `docs/` deben cambiar.
- Actualiza solo documentación respaldada por decisiones o comportamiento real.
- Distingue decisión aprobada, propuesta y pendiente.
- No inventes que modificaste el vault Obsidian si está fuera del workspace.
- Si el vault no está accesible, genera una nota breve para que el usuario la copie a Obsidian y menciona la ruta recomendada.
- Registra cambios de arquitectura/dominio en ADR o registro de decisiones cuando corresponda.
- Mantén los criterios de aceptación y pruebas alineados con la implementación.
